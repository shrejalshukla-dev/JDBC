# JDBC Experiment – Java Database Connectivity

## Aim
To write a Java program using JDBC (Java Database Connectivity) to connect a Java application with a MySQL database and perform database operations.

## About the Experiment
JDBC is a Java API that allows Java applications to connect to databases, execute SQL queries, and retrieve or update data.

## Technologies Used
- Java
- JDBC
- MySQL
- Visual Studio Code
- MySQL Connector/J

## Requirements
- JDK installed
- MySQL Server installed and running
- MySQL Connector/J JDBC driver
- Visual Studio Code

## Database Configuration
- **Database Name:** `shopsphere1`
- **Database URL:** `jdbc:mysql://localhost:3306/shopsphere1`
- **Username:** Your MySQL username
- **Password:** Your MySQL password

## Steps to Execute
1. Install JDK and MySQL Server.
2. Create the MySQL database `shopsphere1`.
3. Add the MySQL Connector/J driver to the Java project.
4. Configure the database URL, username, and password.
5. Compile and run the Java program.
6. Verify the database connection and output.

## Expected Output
```text
Database connected successfully!
```

*Note: The actual output depends on the Java code and database configuration.*

## Learning Outcomes
- Understanding JDBC connectivity.
- Connecting Java applications to MySQL.
- Executing SQL queries using Java.
- Handling database connection exceptions.
